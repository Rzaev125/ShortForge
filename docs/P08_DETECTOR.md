# Локальное обнаружение лиц в Windows

ShortForge читает выбранную видеодорожку исходника через FFmpeg и передаёт кадры отдельному процессу `ShortForge.FaceDetector.exe`. Процесс вызывает `Windows.Media.FaceAnalysis.FaceDetector.DetectFacesAsync`. На выходе получаются прямоугольники лиц. WinRT возвращает их без имени, оценки уверенности и признака говорящего. [API Microsoft](https://learn.microsoft.com/en-us/uwp/api/windows.media.faceanalysis.facedetector)

При сборке `dotnet build ShortForge.slnx -c Release` проект Infrastructure автоматически вызывает компилятор через `scripts/Build-FaceDetector.ps1`. Для сборки из исходников нужны Visual Studio Build Tools с компонентом **MSVC x64/x86** и **Windows 11 SDK 10.0.26100.0**. Скрипт использует установленные инструменты. Готовое приложение находит адаптер в своей папке. Доступность детектора и поддержку Gray8 оно проверяет при запуске анализа. [Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) · [Архив Windows SDK](https://developer.microsoft.com/windows/downloads/sdk-archive/)

## Какие кадры анализируются

FFmpeg сохраняет отображаемую ориентацию и учитывает соотношение сторон пикселя. Интервал выборки задаётся в миллисекундах, от 100 до 2000. Первый отсчёт соответствует началу клипа. Конец интервала исключён. Промежуточный ключевой кадр перед началом клипа позволяет декодировать уже показанное изображение при VFR. Кадры Gray8 помещаются в границы 640 × 640 и идут по локальным каналам процессов. Детектор обрабатывает один кадр за раз. Отмена завершает процессы конкретной операции. Предел одного прохода составляет 3600 отсчётов и 20 минут.

Смену плана оценивает отдельная эвристика. Она сравнивает среднюю яркость сетки 24 × 16 с предыдущим отсчётом. Граница отмечается при средней разнице более 35 из 255 и изменении более половины ячеек как минимум на 29 уровней. Резкая смена освещения может дать ложную границу. Похожие по яркости планы или короткая вставка между отсчётами могут остаться незамеченными.

## Проверка на Windows

Из корня проекта запустить `dotnet test tests/ShortForge.Infrastructure.Tests -c Release --filter FullyQualifiedName~FaceAnalysisTests`. Тест декодирует видео с частотой 1 кадр/с из пути с кириллицей и апострофом. Проверяются выборка от 0,375 до 2,210 с, восемь отсчётов при шаге 250 мс, смена плана, отсутствие лиц, поиск внутри длительности последнего показанного кадра и отмена во время анализа. [Результат Windows-теста](../artifacts/p08-detector/MyPC_DESKTOP-G3NMOOU_2026-11-20_19_47_06_net10.0.trx)

На шести секундах интервью NASA с Пирсом Селлерсом (26–32 с) при шаге 250 мс детектор вернул одно лицо на каждом из 24 кадров. Прямоугольники первого и последнего кадров в пикселях при 640 × 360 — (235, 62, 123, 177) и (167, 58, 126, 179). [Все 24 измерения](../artifacts/p08-detector/piers26-32.txt)
