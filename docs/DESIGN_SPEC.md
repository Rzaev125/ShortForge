# Визуальная спецификация

## Направление

Современный настольный инструмент для монтажа. Спокойный тёмный фон, крупный контент,
понятная иерархия, один акцентный цвет. Не маркетинговый лендинг и не dashboard с
выдуманными графиками. Интерфейс на русском. Рабочее название ShortForge.

## Навигация

Левая панель 208–224 px: логотип/название, «Проекты», «Очередь», «Настройки».
Внизу — краткий статус обработки. Не занимать половину экрана огромной шапкой.
При редакторе sidebar сворачивается, чтобы сохранить пространство видео и таймлайна.

## Экран проектов

- Верх: «Проекты», кнопка «Добавить видео».
- Первый запуск: аккуратная drop-zone, 1–2 строки объяснения и кнопка выбора файла.
- После импорта: список/сетка реальных проектов, thumbnail, название, длительность,
  последняя правка, статус обработки. Нет фиктивных демо-проектов.
- Ошибка импорта показывается рядом с файлом; пользователь может выбрать другой.
- Поддерживаемые форматы описывать «распространённые форматы через FFmpeg» без «любой файл».

## Экран настройки анализа

Выбранный исходник + длительность/дорожка. Язык, диапазон длительности, количество,
режим выбора моментов. Сложные настройки модели в раскрываемом блоке.
Кнопка «Найти фрагменты»; рядом явное «Локально» или название включённого провайдера.
При недостающей модели — конкретное действие «Выбрать модель», без бесконечной загрузки.
Для видео без речи предложение ручного клипа вместо бессмысленного запуска ASR.

## Состояние обработки

Список этапов с текущим шагом: «Читаем видео», «Распознаём речь», «Подбираем фрагменты».
Показывать завершённые этапы, прошедшее время и реальный прогресс там, где он известен.
«Отменить» остаётся доступной. Не обещать время завершения без измерений.
По ошибке — понятное объяснение, «Повторить», «Открыть диагностику».

## Результаты анализа

Карточки с thumbnail, названием, In/Out, длительностью, первым предложением и причиной выбора.
Select checkbox, просмотр, открыть в редакторе, отклонить. Переключатель списка/карточек — optional.
Показывать тип выбора: «Вручную», «По структуре речи», «Смысловой анализ».
Не использовать показатель «98% вирусности». Оценка качества — объяснимая внутренняя подсказка.

## Редактор: 1440×900

| Зона | Размер / содержание |
|---|---|
| Верхняя строка | 56–64 px: назад, имя проекта, autosave state, экспорт |
| Слева | 240–280 px: клипы / расшифровка, поиск по тексту |
| По центру | Гибкая область: вертикальный preview, play, время, safe-area toggle |
| Справа | 280–320 px: вкладки «Кадр», «Субтитры», «Звук» |
| Снизу | 160–220 px: timeline, In/Out, zoom, курсор воспроизведения |

В 1280×800 правая/левая панель сворачиваются; не уменьшать текст до нечитаемого.
Пользователь видит несохранённые правки/ошибки сохранения, а не вечное «Сохранено».
Video controls не перекрывают текст субтитров в реальном экспортном кадре.

## Редактирование

- Space — play/pause; стрелки — короткий seek; Ctrl+Z/Ctrl+Y — undo/redo.
- Горячие клавиши не работают как монтажные команды при наборе текста в input/textarea.
- In/Out редактируются числом и на timeline; видны итоговая длительность и пределы исходника.
- Crop drag с ограничением области; кнопки «Сбросить» и «Вписать».
- Субтитры правятся в списке с таймкодами, выделение строки перемещает playhead.
- Настройки шрифта/цвета/позиции показывают результат сразу; «Точный предпросмотр» рендерит
  небольшой участок тем же FFmpeg/libass pipeline, что и итоговый MP4.
- Safe-area guides имеют подпись «Ориентировочно» и не попадают в экспорт.

## Очередь и экспорт

Количество выбранных клипов, preset, папка, ожидаемый объём только если есть обоснованная оценка.
Для каждого job: этап, прогресс, отменить/повторить, выходной файл после валидации.
Готовый batch: «Открыть папку», ошибки отдельных клипов не маскируются общей зелёной галочкой.

## Motion и доступность

Микроанимации 120–180 ms; без постоянного пульсирования, стекла и тяжёлых размытий.
Учитывать prefers-reduced-motion. Явный focus, подписи и tooltip для icon-only кнопок,
ошибки обозначаются текстом и цветом. Входящие события прогресса не должны красть фокус.

## Проверка дизайна

Скриншоты реальных состояний: пустой экран, проект, обработка, редактор, ошибка, очередь.
Проверить 1280×800 и 1440×900, DPI 125/150%, длинное русское имя файла и длинный текст.
Отчёт должен разделять браузерный preview интерфейса и проверку настоящего Windows-окна.
