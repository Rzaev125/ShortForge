# Приёмочные проверки

Все результаты вносить в STATUS.md: ОС, версии, входной материал, команда/действие,
ожидаемый/фактический результат, ссылка на лог/артефакт. Не отмечать тест пройденным по коду.

## Тестовый набор

Технические fixtures можно генерировать FFmpeg; хранить генератор и маленькие fixtures.
Реальные видео пользователя — вне git, в локальной папке. Не скачивать случайные чужие
полные ролики для тестов. Речь и качество моментов проверять на пользовательских или
разрешённых материалах отдельно от синтетических полос/тона.

| ID | Материал | Что проверяет |

| F01 | H.264/AAC 1920×1080, речь 2–5 минут | Основной путь |

| F03 | Видео без аудио | Честный отказ ASR, ручной монтаж |

## A — окружение и интерфейс

- A01: Сборка C# и UI на чисто восстановленных зависимостях.
- A02: Windows-окно открывается без dev-сервера в publish mode.
- A03: 1280×800, 1440×900, Windows DPI 125/150%; controls не пропадают.
- A04: Полная навигация клавиатурой; hotkeys не ломают ввод текста.
- A05: Пустые состояния, отсутствие FFmpeg/модели и backend errors объясняются.
- A06: Посторонний origin/неизвестная bridge-команда отклонены.

## B — медиа и проекты

- B01: Реальные probe-метаданные совпадают с внешним ffprobe на F01/F02.
- B02: Прокси ищется/воспроизводится, исходник остаётся неизменным.
- B03: Save/restart/open сохраняет границы, текст, crop и выбранные клипы.
- B04: Relink не принимает случайный другой файл без проверки/объяснения.
- B05: Миграция БД сохраняет существующие проекты; ошибки не уничтожают БД.
- B06: Нет чтения гигабайтного видео целиком в managed/JS память.

## C — время, ASR и субтитры

- C01: Unit tests для start/end, единиц времени, clipping/rebase и VFR-путей.
- C02: На F10 выбрать эталонный фрагмент речи 60–120 секунд и вручную сверить текст.
  Записать пропуски/искажения и модель; не объявлять «99% точности» без подсчёта.
- C03: Проверить минимум 20 заметных слов/начала фраз в нескольких частях записи.
  Рабочая цель: не менее 90% выбранных границ в пределах ±250 ms на чистой речи.
  Это критерий проекта, не обещание whisper. При провале — alignment/ручная правка
  либо честный сегментный режим; word-highlight не считать принятым.
- C04: Тишина не генерирует длинные повторяющиеся субтитры.
- C05: Субтитр, пересекающий In/Out, обрезается и получает корректное clip-relative время.
- C06: Изменение текста инвалидирует subtitle/export cache, но не исходную ASR.
- C07: Emoji, кириллица, ə/ı/ş/ğ/ö/ü, braces, backslash и HTML не ломают экспорт.
- C08: Render-preview и итоговый файл совпадают по wrap/font/позиции на одном кадре.

## D — качество подбора

Технические критерии обязательны для всех предложений:
- Валидные исходные segment IDs, интервалы в видео и заданном диапазоне длительности.
- Нет идентичных повторов; слишком близкие/перекрывающиеся кандидаты объединены/объяснены.
- Заголовок/причина не содержат выдуманного содержания.
- Ошибочный ответ провайдера не меняет проект и не запускает команды.

Ручная приёмка semantic-provider: минимум 3 разных речевых видео, до 10 верхних
предложений на каждом, либо все, если кандидатов меньше. Для каждого оценить 0/1:
самостоятельность, законченность, отсутствие обрыва слов, соответствие заголовка.
Цель первой версии: ≥70% рассмотренных предложений проходят все четыре пункта.
Отдельно записать субъективную полезность/интересность; это не прогноз просмотров.
Если материала мало — качество остаётся непроверенным, а не экстраполируется по одному примеру.
Сравнить semantic-provider с режимом правил на том же наборе; не считать LLM улучшением автоматически.

## E — crop и экспорт

- E01: Экспортировать три клипа разных длительностей с burn-in captions.
- E02: Внешний ffprobe подтверждает MP4, video H.264, 1080×1920, yuv420p, SAR=1:1,
  audio AAC при наличии исходного аудио. Разница с целевой длительностью — в разумных
  пределах кодирования, ориентир до 100 ms; объяснить encoder priming/container duration.
- E03: Ручная проверка A/V sync в начале/середине/конце, без накопленного рассинхрона.
- E04: Проверить поворот, VFR, отсутствие аудио, две дорожки, чёрные поля/fit, лица у края.
- E05: Экспорт повторяет crop trajectory и не рисует safe-area guides.
- E06: Сверить исходный hash/метаданные — исходник не изменён.
- E07: Ошибка одного задания не останавливает всю очередь без объяснения.
- E08: Нехватка места, занятый путь, отсутствие права записи не создают «успешный» файл.
- E09: Выходной MP4 воспроизводится внешним проигрывателем; загрузка на платформу
  считается проверенной только после реального действия пользователя, не по расширению MP4.

## Критические причины не принимать сборку

Потеря/перезапись исходника, несохранённые правки, скрытый облачный upload, утечка ключа,
ложный Completed, неправильные интервалы, значимый A/V drift, экспорт без сделанных правок,
невозможность отменить процесс, систематически обрезанные лица/субтитры без fallback.
