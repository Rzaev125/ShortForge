# Продуктовые требования

## Пользователь и сценарий

Один пользователь на Windows. Интерфейс на русском, исходные видео могут быть
на русском/английском и других поддерживаемых ASR языках. Цель — экономить время
на подготовке коротких фрагментов из подкастов, интервью, уроков и обзоров.

Сценарий:
1. Создать проект и выбрать локальное видео.
2. Указать язык, аудиодорожку, длительность и желаемое количество клипов.
3. Запустить обработку, видеть текущий этап, иметь возможность отменить.
4. Получить расшифровку и ранжированные предложения без гарантии заданного количества.
5. Быстро посмотреть, выбрать, исправить начало/конец, кадр и субтитры.
6. Экспортировать выбранные MP4, открыть папку и загрузить самостоятельно.

## Настройки по умолчанию

| Параметр | Значение / поведение |
|---|---|
| Соотношение сторон | 9:16 |
| Выход | 1080×1920, MP4, H.264/AAC, yuv420p, CFR 30 |
| Длительность | 30–60 секунд; также 15–30 и 60–180, свой диапазон |
| Число предложений | До 10, ограничено качеством и длиной материала |
| Перекрытие | Предпочитать самостоятельные неповторяющиеся фрагменты |
| Субтитры | Включены, нейтральный контрастный пресет |
| Язык | Авто + ручной выбор |
| Обработка | Локально; облако выключено |
| Рендер | Одно тяжёлое задание одновременно |
| Исходник | Ссылка на файл, никаких изменений |
| Экспорт | Папка по выбору пользователя, без молчаливой перезаписи |

Поддержка формата определяется реальной сборкой FFmpeg и кодеками, а не расширением.
Парольные, DRM-защищённые и повреждённые файлы не обещаются как поддерживаемые.
Для видео без речи доступен ручной монтаж; смысловой выбор по расшифровке неприменим.

## Режимы выбора моментов

1. «Вручную»: пользователь задаёт границы по видео/расшифровке.
2. «По структуре речи»: локальные правила пауз/предложений/длины. Не выдавать за LLM.
3. «Смысловой анализ»: проверенный локальный либо опциональный облачный провайдер.

Для облачного режима заранее показать: какой провайдер, что передаётся (текст и таймкоды),
приблизительный объём и способ оценки затрат. Не писать «бесплатно» без основания.
Подписка на чат-продукт сама по себе не предполагает доступ/оплату API.
Видео и аудио не передавать, если выбран только текстовый анализ.

## Что такое качественный клип

- Содержит понятную мысль, историю, ответ или совет.
- Не начинается с оборванного слова или ответа без необходимого контекста.
- Заканчивается до начала новой темы и после завершения текущей мысли.
- Заголовок соответствует сказанному, не приписывает несуществующие заявления.
- Нет повторяющихся фрагментов для искусственного достижения количества.
- Оценки в UI объясняют пригодность; не являются прогнозом просмотров/«вирусности».

## Субтитры

Исправляемый текст, сегментные/словные времена, 1–2 строки по умолчанию,
несколько стилей, safe-area overlay, экспорт burn-in и SRT.
Исправления текста не запускают заново ASR. При добавлении слов без времён
нужна ручная/автоматическая повторная привязка либо честный сегментный режим.
Зоны интерфейса TikTok/YouTube — ориентировочные настраиваемые шаблоны, а не вечная гарантия.

## Кадрирование

Обязательны ручной crop и fit. Автоматическое слежение за лицом входит в завершающий
этап MVP. Для двух собеседников допустим надёжный статический шаблон с ручной коррекцией.
Автоматическое переключение на говорящего — последующее развитие, если нет проверенного AV-модуля.

## Критерий готовности продукта

Не только красивое окно: новый реальный файл проходит весь путь до внешне воспроизводимых
MP4. Приложение сохраняет результат, корректно отменяет работу и сообщает об ошибках.
«Идеально готово» означает выбранный технический preset и удобную проверку пользователем,
а не отсутствие любых ошибок ИИ или обещание одобрения/охватов платформы.
