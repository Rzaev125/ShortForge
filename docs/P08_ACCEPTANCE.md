# P08 · Приёмка автоматического кадрирования на Windows

20 ноября 2026 года на Windows 11 x64, сборка 26300, проверены четыре критерия P08. Использованы WPF, WebView2, системный детектор Windows.Media.FaceAnalysis и локальные FFmpeg/ffprobe. Работа шла в новых тестовых библиотеках. [Журнал трёх запусков WPF](../artifacts/smoke/autoframe-14cc0abb2a714ed980726ad0dda393a6/results.txt) · [Измерения и прямоугольники лиц](../artifacts/smoke/autoframe-14cc0abb2a714ed980726ad0dda393a6/decoded.json)

Среди 13 совпадающих по времени пар декодированных кадров наибольшая средняя абсолютная разница яркости составила 0,504 уровня из 255. Независимая сверка с исходниками на 18 кадрах дала максимум 1,599. Для каждого файла ffprobe подтвердил H.264, 1080×1920, yuv420p, SAR 1:1, 30 кадров/с и ожидаемую длительность. Для оценки плавности скрипт сопоставляет яркость каждого из 255 декодированных кадров MP4 с разными горизонтальными вырезами исходного кадра. При 30 кадрах/с максимальное смещение между соседними кадрами составило 4 пикселя исходника, максимальное изменение шага — 2 пикселя. Наибольшее отклонение найденной позиции от интерполированной траектории — 1,479 пикселя. Визуально на листе кадров лицо остаётся внутри кадра и при наклоне человека.

Во время сохранения MP4 в окне были включены направляющие. В декодированных кадрах проверены четыре полосы вдоль границ направляющих. Среди проверенных тёмных пикселей не появилось пикселей, яркость которых выше эталона более чем на 45 уровней. На окнах 1280×800 и 1440×900 проверена ширина диалога при системных 96 DPI и масштабе WebView 125%/150%. Команды для PowerShell из корня проекта после восстановления зависимостей.

```powershell
npm.cmd --prefix src/ShortForge.Ui run build
dotnet build ShortForge.slnx -c Release --no-restore -m:1 -p:UseSharedCompilation=false
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test-AutoFrame.ps1
```

Сценарий печатает путь новой папки `artifacts/smoke/autoframe-…`. В ней остаются исходные технические ролики, MP4 из приложения, журналы, пробы потоков, кадры и измерения. Для независимого повторения сравнения можно передать путь папки и `tools/bin` скрипту `node scripts/Check-AutoFrame.cjs`. [Сборка материалов и запуск WPF](../scripts/Test-AutoFrame.ps1) · [Проверка декодированного изображения](../scripts/Check-AutoFrame.cjs)

Результат характеризует конкретное интервью при хорошем освещении. Длительное естественное перекрытие, съёмка в толпе, движение двух людей, пользовательская оценка плавности и переключение нативного DPI Windows в этом прогоне не проверялись.
