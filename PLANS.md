# План разработки ShortForge

Версия требований: 1.0, 2026-11-20. Целевая ОС: Windows 11 x64.
Рабочая папка по умолчанию: `D:\Projects\ShortForge` (можно выбрать другую).

## Результат первой версии

Пользователь открывает разговорное видео, получает расшифровку и предложенные
самостоятельные фрагменты, правит границы/субтитры/кадр, экспортирует несколько MP4 9:16.
Проекты сохраняются. Тяжёлая задача отменяется. Ошибка одного клипа не уничтожает остальные.
Основная обработка локальная. Облако не требуется для запуска программы и ручного монтажа.

Не входят в первую версию: аккаунты, подписки, публичный веб-сервис, автопубликация,
скачивание видео по URL, генерация видео, B-roll, клонирование голоса, музыкальная библиотека,
перевод/дубляж, полноценный многодорожечный редактор и автоматический монтаж игр.

## Порядок и учёт готовности

Этап завершается только при выполнении всех его критериев. Состояния:
NOT_STARTED / IN_PROGRESS / BLOCKED / READY_FOR_REVIEW / DONE.
Блокировка одной интеграции не мешает независимой работе, но не позволяет объявить этап DONE.
